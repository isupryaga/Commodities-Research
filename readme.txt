Commodity Futures Positioning Signal Research Using CFTC COT Data

This project investigates whether extreme commmerical hedger positioning in CFTC Commitment of Traders data predicts directional price movement in commmodity futures. Using historical COT positioning data across multiple agriculture markets, I developed signal rules based on tail positioning extremes and evaluated their predictive and portfolio performance throuigh backtesting.


Because signal rules were developed iteratively on the historical dataset, reported backtest results may contain in-sample bias. A next step would be strict chronological holdout validation and walk-forward testing.
